# 🎓 Student Management System (CLI)

A simple and interactive Command Line Interface (CLI) based Student Management System built using Python and Object-Oriented Programming (OOP) fundamentals.

---

## 🚀 Features
- **Object-Oriented Design**: Uses Python `class`, constructor (`__init__`), instance attributes, and methods.
- **Interactive CLI Menu**: Menu-driven interface powered by a continuous `while` loop.
- **Add Students**: Dynamically input student details (Name, Roll Number, Marks).
- **Automated Grading**: Real-time grade evaluation (Grade A, B, C, D, Just Pass, Fail) based on scored marks.
- **View Records**: Clean formatted list displaying all registered students and their grades.

---

## 🛠️ Python Concepts Used
- **OOPs**: Classes, Objects, Constructor (`__init__`), Methods (`self`)
- **Data Structures**: Lists (`append()`, iteration)
- **Control Flow**: `if-elif-else` conditional statements & `while True:` loop
- **String Formatting**: Formatted strings (f-strings)
- **Type Conversion**: Dynamic user input casting (`int()`, `str`)

---
